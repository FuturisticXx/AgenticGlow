# Security Policy

## Supported Versions

Only the latest published release is actively supported for security fixes. Users are encouraged to upgrade promptly when new releases are announced.

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

Report security vulnerabilities privately through GitHub's [Private Vulnerability Reporting](https://github.com/FuturisticXx/AgenticGlow/security/advisories/new) feature. This allows responsible disclosure and coordination before public disclosure.

If GitHub private vulnerability reporting is unavailable, report via email to the security contact specified in the repository metadata.

## What to Include

Please include:
- A description of the vulnerability
- Steps to reproduce the issue
- Affected versions
- Potential impact
- Any proposed mitigation (if known)

## Response Expectations

- **Acknowledgment**: Within 7 days of receipt
- **Initial assessment**: Within 14 days
- **Public disclosure**: After a fix is released and users have had reasonable time to upgrade

Security reports are taken seriously. I will work with you to understand and resolve the issue, and coordinate public disclosure timing.

## Coordinated Disclosure

Please do not disclose vulnerabilities publicly before coordination. This gives users time to upgrade and prevents exposing them to known security risks.
